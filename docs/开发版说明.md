# LLMira 开发版说明

本文面向直接下载 LLMira 的个人用户，也说明团队管理员在分发客户端前需要准备的服务。当前版本为 `v0.1.0-dev.1` Developer Preview，不等同于经过商店审核和正式代码签名的稳定版本。

## 下载哪个文件

所有安装包统一放在 [GitHub Releases](https://github.com/fangtoast/LLMira/releases)，源码仓库不提交大体积二进制文件。

| 设备 | 推荐文件 | 备用文件 |
| --- | --- | --- |
| Windows 10/11 x64 | `LLMira_*_x64-setup.exe` | `.msi` 适合系统管理员或批量部署 |
| Android 7.0+ arm64 | `*.apk` | `.aab` 只用于应用商店，不应直接安装 |

Release 同时提供 `SHA256SUMS.txt`。下载后可在 PowerShell 校验：

```powershell
Get-FileHash .\LLMira_0.1.0_x64-setup.exe -Algorithm SHA256
```

将输出与 `SHA256SUMS.txt` 中对应文件的值比较；不一致时不要安装。

## Windows 安装

1. 下载 NSIS `setup.exe` 或 MSI；个人用户优先使用 `setup.exe`。
2. 双击安装。开发预览版未配置受信任发布者证书时，Windows 可能显示发布者提醒。
3. 启动 LLMira，填写由你自己或团队管理员提供的 HTTPS 服务地址。
4. 首次部署由第一位用户创建管理员和默认工作区；个人使用不需要邀请任何成员。

## Android 安装

1. 下载 APK，不要下载 AAB。
2. 在 Android 系统设置中，仅为当前浏览器或文件管理器临时允许“安装未知应用”。
3. 安装完成后可关闭该权限，再启动 LLMira 并连接服务地址。
4. 开发版使用 CI 开发签名；正式签名启用前，下一版可能需要先卸载旧开发版再安装。

Release 流水线会优先使用仓库配置的私有 Android 签名 Secret。没有正式 Secret 时，流水线仅为 Developer Preview 生成临时开发签名，Release 说明会保留这一风险提示。

## 个人与团队的区别

- **个人使用：** 默认工作区、个人 BYOK、对话、知识库、模型对比、Agent、MCP 与定时任务；
- **团队扩展：** 成员邀请、工作区角色、团队密钥、共享资料、协作授权、用量与审计；
- 邀请成员只属于团队扩展，不是个人安装或首次登录步骤。

## 已知边界

- 客户端必须连接 LLMira 服务；当前不提供纯本地服务器或完整离线知识库；
- Windows 安装包尚未配置正式 Authenticode 证书；
- Android 开发签名不用于应用商店正式发布；
- 扫描件 OCR 与 Windows 本机 stdio MCP 桥接尚未完成最终适配；
- iOS 不在当前版本范围。

部署服务见[部署与恢复](部署与恢复.md)，自行构建与正式签名见[发布与打包](发布与打包.md)。
