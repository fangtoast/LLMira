# 发布与打包

本说明覆盖首发 Web、Windows x64 和 Android arm64。iOS 不在当前默认范围。

## Web

```powershell
npm ci
npm run check
docker build -t llmira-web .
```

Next.js 构建产物在 `out/`，由 Caddy 提供静态文件和 `/api`、`/v1` 反向代理。

## Windows x64

前置：Node 24、Rust stable、Visual Studio C++ Build Tools、WebView2，以及 Tauri 获取的 WiX/NSIS 工具。

```powershell
npm ci
npm run tauri:build:windows
```

窗口默认 1440×900，最小 1024×720。输出包括 MSI 和 NSIS；正式分发前配置发布方证书和时间戳服务。

## Android arm64

前置：JDK 17、Android SDK/NDK、`ANDROID_HOME` 和 `aarch64-linux-android` Rust target。

```powershell
npm run tauri:android:init
npm run tauri:build:android -- --target aarch64 --ci
```

输出 APK 与 AAB。上传商店前必须使用私有 keystore 签名；keystore 和 `keystore.properties` 不得提交仓库。

## 流水线

| 文件 | 门禁/产物 |
| --- | --- |
| `.github/workflows/quality.yml` | lint、类型、单元/集成、静态导出、体积、Rust |
| `.github/workflows/release-windows.yml` | Windows x64 MSI/NSIS 草稿发布 |
| `.github/workflows/release-android.yml` | Android arm64 APK/AAB artifact |

本机无法满足某个平台前置条件时，以 CI 对应构建成功作为打包验收，不把“工程已生成”误报为“安装包已验证”。
