# 发布与打包

本文面向维护者，说明 LLMira Web、Windows x64、Android arm64 的构建与 GitHub Release 交付。普通用户请直接阅读[开发版说明](开发版说明.md)。

## 交付原则

- 源码仓库不提交 MSI、EXE、APK、AAB 等大体积二进制文件；
- 推送 `v*` 版本标签后，由 `.github/workflows/release.yml` 在同一次运行中构建 Windows 与 Android；
- 两个平台的安装包、AAB 和 `SHA256SUMS.txt` 作为同一个 GitHub Prerelease 的附件；
- `workflow_dispatch` 可用于无 Release 的构建演练，产物只保留为 Actions artifact；
- Windows 与 Android 任一构建失败时，不创建不完整 Release。

## 发布开发版

先确保 `master` 的质量门禁通过，并同步 `package.json`、`src-tauri/tauri.conf.json` 与 `src-tauri/Cargo.toml` 中的应用版本。开发预览标签使用 SemVer 预发布格式：

```powershell
git tag -a v0.1.0-dev.1 -m "LLMira v0.1.0-dev.1"
git push origin v0.1.0-dev.1
```

流水线完成后检查：

1. Release 标记为 Prerelease；
2. Windows 至少包含 NSIS `setup.exe` 和 MSI；
3. Android 至少包含 arm64 APK，并可附 AAB；
4. `SHA256SUMS.txt` 覆盖所有附件；
5. Release 说明明确开发签名与服务器依赖。

## Web

```powershell
npm ci
npm run check
docker build -t llmira-web .
```

Next.js 使用 `output: "export"`，构建产物位于 `out/`。Caddy 提供静态文件，并将 `/api` 与 `/v1` 代理到独立 API 服务。

## Windows x64

前置：Node 24、npm 11.6、Rust stable、Visual Studio C++ Build Tools、WebView2，以及 Tauri 获取的 WiX/NSIS 工具。

```powershell
npm ci
npm run tauri:build:windows
```

本地产物位于：

- `src-tauri/target/release/bundle/nsis/*.exe`
- `src-tauri/target/release/bundle/msi/*.msi`

窗口默认 1440×900，最小 1024×720。Developer Preview 可以发布未签名安装包，但稳定版本必须配置 Authenticode 证书和时间戳服务。

## Android arm64

前置：JDK 17、Android SDK/NDK、`ANDROID_HOME` 和 `aarch64-linux-android` Rust target。

```powershell
npm run tauri:android:init
npm run tauri:build:android -- --target aarch64 --ci
```

本地产物位于 `src-tauri/gen/android/app/build/outputs/`。APK 用于直接测试安装，AAB 用于 Google Play 等商店上传。

### 签名策略

正式发布需在 GitHub Actions Secret 中配置：

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

keystore、密码和生成后的 `keystore.properties` 不得提交仓库。Developer Preview 在没有正式 Secret 时生成一次性开发签名，使 APK 可以测试安装；由于签名可能变化，后续版本可能需要卸载重装。

## 流水线

| 文件 | 门禁/产物 |
| --- | --- |
| `.github/workflows/quality.yml` | lint、类型、单元/集成、静态导出、体积与 Rust |
| `.github/workflows/release.yml` | Windows x64 MSI/NSIS、Android arm64 APK/AAB、SHA-256 与 GitHub Prerelease |

本机无法满足某个平台前置条件时，以 GitHub Actions 对应构建成功和 Release 附件存在作为打包验收，不能把“工程已生成”或“工作流已配置”写成“安装包已验证”。
